# Controls

All hot keys are reconfigurable from the options dialog (F12 -> Shortcuts).
Defaults below. The "with modifier" shortcuts use the **Alt** modifier by
default.

## Default shortcuts

| Key          | Action                                    |
|--------------|-------------------------------------------|
| `F12`        | Open the options dialog                   |
| `F11`        | Toggle fullscreen                         |
| `Alt+O`      | Open the options dialog                   |
| `Alt+F`      | Toggle fullscreen                         |
| `Alt+P`      | Pause / resume emulation                  |
| `Alt+D`      | Open the m68k debugger                    |
| `Alt+I`      | Open the i860 (NeXTdimension) debugger    |
| `Alt+M`      | Grab / release the host mouse             |
| `Alt+C`      | Cold reset                                |
| `Alt+G`      | Save a screenshot                         |
| `Alt+R`      | Start / stop recording                    |
| `Alt+S`      | Toggle sound                              |
| `Alt+Q`      | Quit                                      |
| `Alt+N`      | Toggle the NeXTdimension board            |
| `Alt+B`      | Toggle the status bar                     |
| `Alt+T`      | Toggle the title bar                      |

## Options dialog keys

| Key     | Action                                       |
|---------|----------------------------------------------|
| `Tab`   | Move to the next control                     |
| `Enter` | Activate the focused control                 |
| `Esc`   | Cancel / close the dialog                    |
| `F9`    | Apply settings and close (options dialog)    |

## Mouse

While running, the emulated machine captures the host mouse. **Alt+M** grabs
and releases it. The NeXT mouse (and the NeXT tablet, if enabled) are
emulated from the host pointing device.

## Debugger keys

Within the m68k or i860 debugger, `q` quits back to the emulation and `help`
lists available commands.
